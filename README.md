# GymFlow

Projecte del mòdul M07 – Desenvolupament d'interfícies (2n DAM).

**Alumne:** ABDELLAH EL FTOUH EL KAMRI

GymFlow és una aplicació per a un gimnàs amb dues parts:
- **Soci** (app mòbil): reservar classes en pocs passos.
- **Recepció** (escriptori): gestió de socis i classes.
